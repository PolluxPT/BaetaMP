# Changelog

## 1.3.2 — 2026-10-22

- English by default on first launch or when no valid language preference exists; saved PT/EN choices are preserved.
- Capture the console volume before launching the player and restore it on exit, including launcher signal cleanup and guardian recovery.
- Preserve the session volume across internal playback/UI restarts.
- Inglês por defeito na primeira utilização; idioma escolhido preservado. Volume original da consola reposto à saída.

## 1.3.1 — 2026-10-21

- Rounded corners on all buttons, selectable rows, dialogs and keyboard keys.
- Visual-only update: existing colors, layout, touch areas and playback behavior retained.
- Cantos arredondados em todos os botões, listas, confirmações e teclado; alteração apenas estética.

## 1.3.0 — 2026-10-19

- Public project name **BaetaMP** (MP = Media Player).
- Official supplied logo at `APPS/Imgs/BaetaMP.png`.
- App folder and launcher renamed consistently; migration from BaetaMediaPlayer and MediaPlayer_RGDSPlus retains existing user data and old resume keys.
- Source/test/docs layout, reproducible release packaging, GitHub CI and bilingual publication/install guidance.
- Retains the playback behavior from the physically tested 1.2 release.
